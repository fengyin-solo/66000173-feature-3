# solo-6600017: 天文星图交互式渲染器

## 技术栈
- Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS
- Canvas 2D 天文投影渲染

## 核心特性
1. **赤道坐标投影**：RA/Dec → 地平坐标 (Alt/Az) 实时转换
2. **88 星座渲染**：6 个典型星座（猎户/大熊/仙后/天蝎/天鹅/狮子）+ 连线 + 名称
3. **时间旅行**：通过日期时间选择器查看任意时刻的星空
4. **天体搜索**：输入星名定位，点击星体显示详细信息
5. **光谱色彩**：O/B/A/F/G/K/M 七种光谱类型对应不同颜色
6. **交互控制**：缩放、纬度调节、星名/连线/网格显示开关
7. **可复原观测链接**：当前时间、纬度、缩放、三个显示开关与选中星编码进地址栏，复制出去的链接在他人机器上还原同一片星空与同一颗选中星
8. **最近观测**：每次复制链接自动存入 localStorage（最多 10 条），侧栏一键回到任意一次；无记录时显示空态说明
9. **链接失效保护**：参数被改动后原链接标记失效（红色提示条），不会悄悄替换成另一片星空；参数缺失时静默回退默认，参数非法或越界时回退默认并在页面上说明原因

### 观测链接参数
| 参数 | 含义 | 范围/格式 |
| --- | --- | --- |
| `t` | 观测时间 | ISO 8601 |
| `lat` | 纬度 | -90 ~ 90（默认 39.9） |
| `zoom` | 缩放 | 0.3 ~ 3（默认 1.0） |
| `labels` / `const` / `grid` | 星名标签 / 星座连线 / 坐标网格 | `0` 或 `1`，默认 `1` |
| `star` | 选中星名称 | 须在内置星表中，缺省表示未选星 |

参数缺失按默认处理；给出但无法解析或超出范围的参数退回默认，并在星图上方提示具体原因。

## 启动
```bash
cd frontend && npm install && npm run dev
```
